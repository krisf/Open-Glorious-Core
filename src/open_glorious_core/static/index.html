                                Technical notes
                                
Slots 14, 72, 92 (firmware matrix artifacts), slots 55–59
                                    (the row-4 head cells: factory-0xFF spares with no keycap; G17 retracts the G11 claim
                                    that 58 was Caps Lock) and the five row-6
                                    spacer positions 103, 104, 106, 107, 111 carry no physical keycap on this board
                                    (remap/KEYMAP_MAP.md incl. its SWEEP-VERDICT note) and render as invisible gaps,
                                    not keycaps. Each cap’s slot is a table cell from the map’s row tables
                                    (keymap-slots.js) — the row-4 block starts at slot 60, the Caps Lock cell the
                                    G13 sweep confirmed, all remaining block-trailing spares are not shown.
